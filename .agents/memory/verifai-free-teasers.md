name: VerifAI free-report teasers
description: How upsell teasers on the free report should be worded (no fabricated numbers).
---
Free-report teasers for paid features must not show fabricated counts. The user asked for a "dummy number" to attract paid users, then settled on "not fixed, not exact, a flash line that suggests that we have that" — a numberless teaser line (e.g. "Who's already near you?" for Idea Neighbors).

**Why:** a made-up count that the paid report doesn't match reads as bait and invites refund complaints; the existing teaser strip only uses real counts.

**How to apply:** for new upsell hints, either use a real computed count or numberless copy that names the feature.
